# Fotos

Una carpeta por servicio. Soltar los archivos nuevos aquí y aparecen solos en el sitio.

| Carpeta     | Dónde se usa                                  |
|-------------|-----------------------------------------------|
| `general/`  | Portada (la primera foto) y galería del home  |
| `canchas/`  | Sección Canchas de fútbol y futbolito         |
| `tenis/`    | Sección Canchas de tenis                      |
| `piscinas/` | Sección Piscinas                              |
| `quinchos/` | Sección Quinchos                              |

- Formatos: jpg, png, webp o avif (preferir webp/avif).
- Se ordenan por nombre: usar `01-...`, `02-...`.
- Tamaño sugerido: 2000 px de ancho, menos de 400 KB cada una.
- La portada es la primera foto de `general/` (hoy `01-hero.jpg`, provisoria).
- Las fotos actuales son las del sitio antiguo; se reemplazan por las nuevas.
- `tenis/` está vacía a propósito: la sección muestra un recuadro "próximamente" hasta que haya fotos.
